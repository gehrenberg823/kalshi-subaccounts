Kalshi Subaccounts

Settled P&L per Kalshi subaccount. Subaccount is recorded only on fills, so settled results are attributed by each subaccount's share of fill cost per (strategy, ticker, side). Subaccount 0's automated book and pre-field fills are excluded; the Main Account section shows only Manual Trade fills from the main account (tagged sub 0 before 2026-07-17, untagged after — both are folded in). Subs 1–9 = manual traders. Windowed views count settlements landing in the window (attributed by all-time fill share, so positions filled before the window still count when they settle); Fills / Fill cost show activity in the window. Fill cost > settled cost means open (unsettled) exposure.
